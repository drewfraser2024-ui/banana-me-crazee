# Banana Me CrazEE! 🍌

Website for **Banana Me CrazEE!** — homemade banana pudding in 8 crazy flavors.
Sweet • Creamy • Addictive.

## Pages
- `index.html` — storefront (menu, about, contact, and an "Order Online" flow with a mock checkout)
- `dashboard.html` — Shopify-style owner admin dashboard (sales, orders, products)
- `images/` — logo + product photos

## Notes
- The checkout is a **demo/mock** — it does not process real payments. To take real
  payments, connect Stripe, Square, or PayPal.
- Static site — no build step. Just open `index.html` or serve the folder.
